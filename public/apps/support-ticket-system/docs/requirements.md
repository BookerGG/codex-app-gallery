# Requirements

## Product Brief

The Support Ticket System helps a support team triage customer requests, identify urgent work, and keep ownership clear.

## Target User

A support agent, operations teammate, or small business owner who needs a simple queue for incoming requests.

## User Stories

- As a support agent, I want to view all tickets so I know what needs attention.
- As a support agent, I want to filter by status so I can focus on active work.
- As a support agent, I want to filter by priority so urgent issues stand out.
- As a support agent, I want to search tickets so I can quickly find a customer request.
- As a support agent, I want to create a ticket so new requests can enter the queue.

## MVP Scope

Included:

- Ticket list
- Status filter
- Priority filter
- Search
- Add ticket form
- Summary cards
- Mock data
- Tests for filtering and summary logic

Not included yet:

- Login
- Role permissions
- Database persistence
- Assignment workflow
- SLA notifications

## Acceptance Criteria

- Users can see realistic ticket records when the app loads.
- Users can filter by supported statuses and priorities.
- Users can search text across common ticket fields.
- Users can add a new ticket and immediately see it in the queue.
- Summary metrics update when a new ticket is added.
