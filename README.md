# Codex App Gallery

A living showcase for apps built with Codex.

The first version includes:

- Job Hunt Tracker
- Support Ticket System
- Codex App Gallery

The two existing apps are copied into `public/apps/` so the published gallery can open them as live demos.

The gallery data is generated by `scripts/sync-codex-apps.mjs`. It scans Codex app output folders under `Documents/Codex/**/build/outputs/*`, copies current static app files into `public/apps/`, and refreshes app preview images when the source changes.

## Credit-free automatic updates

Codex scheduled tasks use Codex usage when they run. To keep gallery updates automatic without Codex credits, this project can publish through GitHub Pages instead:

1. `scripts/sync-and-push-gallery.ps1` runs locally on Windows, syncs the source apps, validates the gallery, commits with `work/deploy-source.git`, and pushes to GitHub.
2. `.github/workflows/deploy-pages.yml` builds a static export on GitHub Actions and deploys it to GitHub Pages.
3. `scripts/install-credit-free-auto-update.ps1` registers the local Windows scheduled task.

By default, the local scheduled task checks once per week.

The local script requires GitHub Git credentials once. Sign in with GitHub CLI or Git Credential Manager, then run the initial push:

```powershell
gh auth login
powershell -ExecutionPolicy Bypass -File scripts\sync-and-push-gallery.ps1 -InitialForcePush
powershell -ExecutionPolicy Bypass -File scripts\install-credit-free-auto-update.ps1
```

After GitHub Pages is enabled for the repository, the credit-free URL is expected to be `https://bookergg.github.io/codex-app-gallery/`.

## Commands

```bash
pnpm install
pnpm run sync:apps
pnpm run refresh:apps
pnpm run dev
pnpm run build
pnpm run build:static
pnpm test
```
