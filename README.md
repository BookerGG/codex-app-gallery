# Codex App Gallery

A living showcase for apps built with Codex.

The first version includes:

- Job Hunt Tracker
- Support Ticket System
- Codex App Gallery

The two existing apps are copied into `public/apps/` so the published gallery can open them as live demos.

## Commands

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm test
```

## Notes

- The gallery page lives in `app/page.tsx`.
- The app thumbnails live beside each copied demo as `preview.png`.
- The social preview image is `public/og.png`.
